## 1. 왜 만들려 하나 (Problem)

- 동호회 활동에 **참여 동기** 부여가 필요. 단순 "신청만 하고 안 읽기" / "독후감 미제출" 같은 행동을 시스템적으로 가시화.
- 현재는 관리자가 시트로 수기 관리 — 잊혀짐, 형평성 분쟁, 운영 피로도.
- 게이미피케이션으로 **포인트(긍정 강화) + 벌점(억제)** 의 두 축을 둠으로써 자율 운영 유도.
- README 로드맵 3단계의 핵심 모듈.

## 2. 목표 (Goal)

- 회원별 포인트 / 벌점 이력 추적.
- 행동 트리거(독후감 제출, 기한 초과, 미수령 등) 에 따른 자동 / 관리자 수동 부여.
- 임계치(예: 벌점 5점) 도달 시 액션 (가입 일시 정지, 알림 발송).
- 동호회별 정책 분리 — 무제(독서) 와 다른 동호회의 점수 체계 독립.
